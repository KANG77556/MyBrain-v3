# Brain Assistant 앱 아이콘 설계

## 목표

홈 화면과 앱 서랍에서 작은 크기로도 식별되는 Brain Assistant 아이콘을 제공한다.

## 시각 방향

- 배경: 앱의 생산성·신뢰 인상을 유지하는 파란 원형 바탕
- 전경: 흰색 뇌 윤곽과 완료 체크를 결합한 단순한 마크
- 형태: Android 적응형 아이콘의 안전 영역 안에 배치
- 텍스트·그림자·사진 요소는 사용하지 않는다.

## 구현

- 벡터 drawable로 전경과 배경을 제공해 해상도별 비트맵을 중복 관리하지 않는다.
- 기존 런처 참조를 적응형 아이콘 리소스로 교체한다.
- Debug APK를 빌드해 연결된 Galaxy 기기에 재설치한다.

## 검증

1. `assembleDebug`가 성공한다.
2. APK 설치가 성공한다.
3. 기기의 앱 서랍 또는 홈 화면에서 아이콘이 정상적으로 표시된다.
