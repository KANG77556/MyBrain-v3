# 반복 일정 Google 캘린더 대상 설계

## 문제

반복 일정 게이트웨이가 대상 캘린더 ID가 비어 있을 때 `1`을 사용한다. 연결된 기기에서 ID `1`은 로컬 캘린더이므로 Google Calendar에 동기화되지 않는다.

## 결정

반복 일정과 예외 일정 모두 일반 일정과 같은 기준으로 대상 캘린더를 선택한다.

1. 저장된 숫자 캘린더 ID가 있으면 이를 사용한다.
2. 없으면 표시 중이며 쓰기 권한이 있는 `com.google` 캘린더를 선택한다.
3. 해당 캘린더가 없으면 로컬 캘린더로 대체하지 않고 연결 필요 오류를 반환한다.

## 검증

- 선택 로직은 로컬 ID `1` 대신 Google ID를 반환한다.
- 반복 일정 생성과 예외 일정 생성이 같은 Google ID를 사용한다.
- Debug APK를 기기에 설치하고 반복 일정 저장 후 Google Calendar에 표시되는지 확인한다.
