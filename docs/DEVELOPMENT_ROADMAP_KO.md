# MyBrain AI V2 개발 로드맵

## P0 — 개발 기반 안정화
- `v2` 기준 브랜치 운영 정착
- 모든 표준 작업 브랜치에서 CI 실행
- 저장소/개발 기준선 자동 검사
- Release 서명 Secrets가 없는 환경에서도 미서명 컴파일 검증 유지

## P1 — 핵심 생산성
- 메모·할 일·일정의 저장 무결성과 편집 흐름 강화
- 일정 충돌 감지와 오늘 대시보드 일관성 개선
- 위젯과 앱 본문 상태 동기화 강화
- 백업/복원 회귀 테스트 확대

## P2 — AI 보조
- 한국어 자연어 입력 정확도 개선
- 클라우드 전송 개인정보 필터 강화
- AI 비용/예산·재시도·캐시 정책 고도화
- 실패 시 로컬 기능이 영향을 받지 않는 graceful degradation 유지

## P3 — 접근성·자동화·배포
- 음성 입력과 접근성 설정 개선
- 알림 재예약 및 부팅 복구 안정화
- 앱 내 업데이트 진단/복구 경험 개선
- 릴리스 산출물, 서명, SHA-256 검증 자동화 강화

## 우선순위 규칙
1. 데이터 유실·저장 오류
2. 실행/설치/업데이트 실패
3. 일정·알림 신뢰성
4. 핵심 UX
5. AI 편의 기능
6. 시각적 개선

각 항목은 별도 Issue와 PR로 추적하며, 완료 조건에는 실제 테스트 또는 재현 가능한 검증 근거를 포함합니다.
